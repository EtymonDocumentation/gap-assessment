# Changelog

## 0.1.0

First version. Statistics for the PPQ sampling plan: company table (with `validateCompanyTable`), fixed count, confidence/reliability,
MIL-STD-105E attribute plans (Table I, II-A, II-B, II-C with the arrow rule), MIL-STD-414 variables plans (Section B, standard deviation
method, Form 1 and Form 2, normal, tightened and reduced). See README.md for what is not supported.
